Background

🎨 Background CSS क्या है? Background CSS का इस्तेमाल किसी भी HTML element (जैसे div, body, section) के पीछे का रंग, image या effect लगाने के लिए किया जाता है। 1️⃣ background-color 👉 Element के पीछे color लगाने के लिए body{ background-color: lightpink; } 📌 पूरे page का background गुलाबी हो जाएगा 2️⃣ background-image 👉 Background में image लगाने के लिए div{ background-image: url("bg.jpg"); } 3️⃣ background-repeat 👉 Image को repeat करना है या नहीं div{ background-repeat: no-repeat; } Options: repeat (default) no-repeat repeat-x repeat-y 4️⃣ background-size 👉 Image का size control करता है div{ background-size: cover; } Values: cover → पूरी screen भर देगा contain → पूरी image दिखाएगा 5️⃣ background-position 👉 Image को कहाँ दिखाना है div{ background-position: center; } Examples: top bottom left right center 6️⃣ background-attachment 👉 Scroll करने पर image fix रहे या चले body{ background-attachment: fixed; } 7️⃣ background: shorthand (short तरीका) 👉 एक line में सब कुछ body{ background: pink url("bg.jpg") no-repeat center / cover; } 8️⃣ background: transparent 👉 Background को पूरी तरह transparent करने के लिए div{ background: transparent; } 📌 नीचे का content दिखाई देगा 🧠 Simple Example (Shayari Card) .shayari-card{ background: white; border-radius: 10px; } 🔥 Important Note ❌ गलत

Margin & Padding

📦 Margin और Padding क्या है? CSS में margin और padding किसी element के आसपास और अंदर की spacing (खाली जगह) को control करते हैं। 👉 Simple line में Margin = element के बाहर की जगह Padding = element के अंदर की जगह 🟦 Padding क्या है? 👉 Content और border के बीच की जगह Example: .box{ padding: 20px; } 📌 Text और box के border के बीच 20px का gap आएगा Padding के types: padding-top: 10px; padding-right: 15px; padding-bottom: 20px; padding-left: 25px; Shortcut: padding: 10px 20px; (top-bottom | left-right) 🟥 Margin क्या है? 👉 Element और दूसरे element के बीच की जगह Example: .box{ margin: 30px; } 📌 Box दूसरे elements से 30px दूर हो जाएगा Margin के types: margin-top: 10px; margin-right: 15px; margin-bottom: 20px; margin-left: 25px; Shortcut: margin: 10px 20px; 🧠 Real Life Example |------- Margin -------| | |--- Padding ---| | | | Content | | | |---------------| | |----------------------| 🔥 Margin vs Padding (Difference) Margin Padding बाहर की spacing अंदर की spacing Transparent होती है Background color दिखता है Elements के बीच gap Content और border के बीच gap ⚠️ Important Tip Padding में background color दिखता है Margin में background नहीं दिखता ✨ Example Code .card{ background: pink; padding: 15px; margin: 20px; } अगर आप चाहें तो मैं: 📦 Box Model 🎯 margin auto center ❌ margin collapse भी आसान हिंदी में समझा सकता हूँ 👍

height width

📐 Height और Width क्या है? (CSS) height और width CSS properties हैं, जिनसे किसी भी HTML element की ऊँचाई (height) और चौड़ाई (width) तय की जाती है। 🟥 Width (चौड़ाई) 👉 Element कितना चौड़ा होगा, यह बताता है। Example: .box{ width: 300px; } 📌 Box की चौड़ाई 300px हो जाएगी 🟦 Height (ऊँचाई) 👉 Element कितना ऊँचा होगा, यह बताता है। Example: .box{ height: 200px; } 📌 Box की ऊँचाई 200px हो जाएगी 📏 Units (इकाइयाँ) Height और Width में अलग-अलग units use होती हैं: Unit मतलब px Fixed size % Parent के हिसाब से vh Screen की height vw Screen की width auto Content के हिसाब से Example: .box{ width: 50%; height: 50vh; } 📦 Box Model से Relation 👉 height/width सिर्फ content area की होती है 👉 padding और border जोड़ने से actual size बढ़ जाता है .box{ width: 200px; padding: 20px; } 📌 Total width = 240px 🔥 box-sizing trick .box{ box-sizing: border-box; } 👉 अब padding + border, width/height के अंदर ही रहेंगे ✅ ⚠️ Common Mistakes ❌ गलत height: 200; ✅ सही height: 200px; 🧠 Real Example .card{ width: 300px; height: auto; } 📌 Height content के अनुसार बढ़ेगी ✨ Extra Tip Images के लिए: img{ width: 100%; height: auto; } 👉 Image stretch नहीं होगी अगर आप चाहें तो मैं: 📦 min-height / max-width 📱 responsive sizing 🎯 center box using width भी आसान हिंदी में समझा सकता हूँ 👍

Css display

📺 CSS Display क्या है? display CSS की एक property है, जो ये तय करती है कि कोई HTML element कैसे दिखाई देगा और page पर कितनी जगह लेगा। 1️⃣ display: block 👉 Element नई line से शुरू होता है 👉 पूरी width ले लेता है Example: div{ display: block; } 📌 Examples: div, p, h1 2️⃣ display: inline 👉 Element same line में रहता है 👉 height, width काम नहीं करता Example: span{ display: inline; } 📌 Examples: span, a, strong 3️⃣ display: inline-block 👉 Same line में भी रहता है 👉 height और width भी काम करता है Example: button{ display: inline-block; } 4️⃣ display: none 👉 Element पूरी तरह गायब हो जाता है 👉 space भी नहीं लेता Example: .box{ display: none; } 5️⃣ display: flex 👉 Layout बनाने के लिए सबसे ज्यादा use होता है Example: .container{ display: flex; justify-content: center; align-items: center; } 📌 Elements line में arrange हो जाते हैं 6️⃣ display: grid 👉 Row और column वाला layout Example: .container{ display: grid; grid-template-columns: 1fr 1fr 1fr; } 🧠 Difference Table Display नई line Width/Height Use block ✅ ✅ Sections inline ❌ ❌ Text inline-block ❌ ✅ Buttons none ❌ ❌ Hide flex ❌ ✅ Layout grid ❌ ✅ Layout ⚠️ display vs visibility visibility: hidden; 👉 Element छुपेगा लेकिन जगह रहेगी display: none; 👉 Element और उसकी जगह दोनों हट जाएँगे 🔥 Real Example (Shayari Card) .shayari-container{ display: flex; gap: 20px; } अगर आप चाहें तो मैं: 📦 display practice questions 🎯 flex vs grid difference 💡 real website layout example भी आसान हिंदी में समझा सकता हूँ 👍

Css position

📍 CSS Position क्या है? position CSS की एक property है, जिससे यह तय होता है कि कोई HTML element page पर कहाँ और कैसे रखा जाएगा। 1️⃣ position: static (default) 👉 हर element का default position 👉 top, left, right, bottom काम नहीं करता .box{ position: static; } 2️⃣ position: relative 👉 Element अपनी original जगह से move करता है 👉 Space वहीं रहता है .box{ position: relative; top: 20px; left: 30px; } 📌 Box थोड़ा नीचे-दाएँ खिसक जाएगा 3️⃣ position: absolute 👉 Element parent के हिसाब से move होता है 👉 Space नहीं लेता .parent{ position: relative; } .child{ position: absolute; top: 0; right: 0; } 📌 Child parent के कोने में चला जाएगा 4️⃣ position: fixed 👉 Element screen पर fix रहता है 👉 Scroll करने पर भी नहीं हिलता .nav{ position: fixed; top: 0; } 📌 Navbar हमेशा ऊपर दिखेगा 5️⃣ position: sticky 👉 Scroll पर चिपक जाता है (mix of relative + fixed) .header{ position: sticky; top: 0; } 📌 Scroll करने पर header stick हो जाएगा 🧠 Important Properties Position के साथ ये use होती हैं: top left right bottom z-index 🔥 z-index क्या है? 👉 कौन सा element ऊपर दिखेगा .box1{ z-index: 1; } .box2{ z-index: 5; } 📌 Box2 ऊपर दिखेगा 📊 Comparison Table Position Space लेता है Scroll effect static ✅ normal relative ✅ normal absolute ❌ parent based fixed ❌ fixed sticky ✅ sticky ✨ Real Example (Envelope / Shayari) .cover{ position: absolute; z-index: 3; } 👉 Cover ऊपर दिखेगा अगर आप चाहें तो मैं: 🎯 absolute vs relative deep 💌 envelope animation 📱 mobile layout positioning भी आसान हिंदी में समझा सकता हूँ 👍

z-index

🧱 z-index क्या है? (CSS) z-index CSS की एक property है जो यह तय करती है कि कौन-सा element ऊपर दिखेगा और कौन-सा नीचे। 👉 इसे आप layers (परतों) की तरह समझ सकते हैं। 📊 Simple Example .box1{ position: absolute; z-index: 1; } .box2{ position: absolute; z-index: 5; } 📌 box2 ऊपर दिखेगा क्योंकि उसका z-index ज्यादा है ⚠️ Important Rule (बहुत जरूरी) 👉 z-index तभी काम करता है जब position हो ❌ गलत .box{ z-index: 10; } ✅ सही .box{ position: relative; z-index: 10; } 🔢 z-index values Positive number → ऊपर Negative number → नीचे 0 → normal layer .box{ z-index: -1; } 📦 Real Life Example (Shayari Envelope) .paper{ position: relative; z-index: 1; } .cover{ position: absolute; z-index: 3; } 📌 Cover, paper के ऊपर दिखेगा 💌 🧠 stacking context (simple) अगर parent element में: position: relative; z-index: 1; तो उसके अंदर के elements उसी parent की boundary में रहेंगे। ❓ z-index vs order अगर z-index same है: 👉 जो element HTML में बाद में लिखा होगा, वही ऊपर दिखेगा 🔥 Common Mistakes ❌ position न देना ❌ बहुत ज्यादा z-index (99999) बिना जरूरत 📝 Summary z-index = layer control position जरूरी है ज्यादा value = ऊपर अगर आप चाहें तो मैं: 🎯 z-index interview questions 💥 overlapping card effect 🧠 stacking context deep भी आसान हिंदी में समझा सकता हूँ 👍

Css Animation

🎬 CSS Animation क्या है? CSS Animation का मतलब है किसी HTML element को बिना JavaScript के हिलाना-डुलाना, घुमाना, fade करना या animate करना। 👉 जैसे: button का bounce होना card का slide होना envelope का open होना 💌 🧱 CSS Animation के 2 Parts 1️⃣ @keyframes 👉 Animation के steps बताते हैं 2️⃣ animation property 👉 Animation कैसे चलेगी (time, repeat, direction) ✨ Simple Example (Color change) @keyframes changeColor { from { background: pink; } to { background: red; } } .box{ width: 100px; height: 100px; animation: changeColor 2s infinite; } 📌 Box का color बार-बार बदलेगा 🎯 Position Animation Example (Move) @keyframes moveBox { from { left: 0; } to { left: 200px; } } .box{ position: relative; animation: moveBox 3s infinite alternate; } ⚙️ Animation Properties (Important) animation-name: moveBox; animation-duration: 3s; animation-delay: 1s; animation-iteration-count: infinite; animation-direction: alternate; animation-timing-function: ease-in-out; Short form: animation: moveBox 3s ease-in-out infinite alternate; ⏱️ timing-function क्या है? Animation की speed control करता है linear → same speed ease → slow → fast → slow ease-in ease-out ease-in-out 🔁 iteration-count animation-iteration-count: infinite; 👉 Animation बार-बार चलेगी 🛑 animation-fill-mode animation-fill-mode: forwards; 👉 Animation खत्म होने के बाद last position पर रुक जाएगी 💌 Real Example (Envelope open) @keyframes openCover { from{ transform: rotateX(0deg); } to{ transform: rotateX(180deg); } } .cover{ animation: openCover 2s forwards; } ⚠️ Common Mistakes ❌ @keyframe (गलत) ✅ @keyframes (सही) ❌ duration न देना 👉 animation चलेगी ही नहीं 📝 Summary CSS animation = movement without JS @keyframes जरूरी duration जरूरी अगर आप चाहें तो मैं: 🎯 hover animation 💖 shayari card animation 💌 envelope open animation

Css Transition

🔄 CSS Transition क्या है? CSS Transition का मतलब है जब किसी element की property बदलती है, तो वह बदलाव धीरे-धीरे (smooth तरीके से) हो। 👉 बिना transition के change अचानक होता है 👉 transition के साथ change smooth दिखता है 🎯 Simple Example (Hover Effect) .button{ background: pink; padding: 10px 20px; transition: background 0.5s; } .button:hover{ background: red; } 📌 Hover करने पर color धीरे-धीरे बदलेगा 🧱 Transition के 4 Parts transition: property duration timing-function delay; Example: transition: all 0.3s ease 0s; ⚙️ Transition Properties Explained 1️⃣ transition-property transition-property: width; 👉 कौन-सी property animate होगी 2️⃣ transition-duration transition-duration: 1s; 👉 कितने time में change होगा 3️⃣ transition-timing-function transition-timing-function: ease-in-out; 👉 speed control 4️⃣ transition-delay transition-delay: 0.5s; 👉 delay के बाद start होगा 🔥 Real Example (Card Zoom) .card{ transition: transform 0.4s ease; } .card:hover{ transform: scale(1.05); } ⚠️ Important Points ❌ Transition अपने-आप नहीं चलता 👉 hover / class change / JS से trigger होता है ❌ display पर transition काम नहीं करता 🆚 Transition vs Animation Transition Animation Trigger चाहिए Auto चल सकती है Simple effects Complex effects Hover best Loop, keyframes 📝 Summary Transition = smooth change Trigger जरूरी Hover effects के लिए best अगर आप चाहें तो मैं: 💌 envelope open transition 🎯 button hover effects 📱 real website transition examples भी बना कर समझा सकता हूँ 👍

Css Rounded Corners

🔵 CSS Rounded Corners क्या है? Rounded Corners का मतलब है किसी box, image, button आदि के कोने (corners) गोल करना। 👉 CSS में यह काम border-radius property से किया जाता है। 🟦 border-radius का use Example: .box{ width: 200px; height: 100px; background: pink; border-radius: 20px; } 📌 Box के चारों कोने गोल हो जाएंगे 🔢 border-radius के तरीके 1️⃣ All corners same border-radius: 15px; 2️⃣ Different corners border-radius: 10px 20px 30px 40px; 📌 Order: top-left → top-right → bottom-right → bottom-left 3️⃣ Circle बनाना .circle{ width: 100px; height: 100px; border-radius: 50%; } 📌 Perfect गोल shape बनेगा ⚪ 4️⃣ Pill / Capsule shape (Button) .button{ border-radius: 50px; } 📌 Button tablet जैसा दिखेगा 🖼️ Image rounded corners img{ border-radius: 10px; } 💌 Real Example (Shayari Card) .shayari-card{ background: white; border-radius: 12px; } ⚠️ Important Tips ज्यादा border-radius देने से shape पूरी गोल हो सकती है % responsive design में अच्छा रहता है 📝 Summary Rounded corners = गोल किनारे border-radius से बनता है Box, image, button सभी में use होता है अगर आप चाहें तो मैं: ✨ advanced shapes 💖 card design 📱 mobile friendly rounded UI भी बना कर समझा सकता हूँ 👍 Want to keep using GPT-5?
